# 💸 PayFlow

**PayFlow** is a modern full-stack digital wallet and payment application. It allows users to register, log in, check balances, and transfer money securely. Built with React, Node.js, and MongoDB.

---

## ✨ Features

- 🔐 JWT-based Authentication (Register/Login)
- 👤 User profile with wallet balance
- 💸 Send money to other users
- 🔍 Search and find users
- 🎨 Modern, responsive UI
- 🔒 Secure transactions with MongoDB ACID compliance
